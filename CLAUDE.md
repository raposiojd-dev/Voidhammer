# Working in this repo

- UI, menus, HUD, web pages and screens: use the `impeccable` skill (`.claude/skills/impeccable`) to design, critique and polish. The game's existing look is the brief; refine it, don't replace it.
- Any player-facing writing (dialogue, quest text, lore, store copy): run it through the `humanizer` and `stop-slop` skills. In-world sayings, names and canon stay exactly as they are. Australian spelling.
- Test on an 844x390 landscape viewport with no page errors before committing.
